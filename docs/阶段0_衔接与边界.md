## 0.4 生态网络的逻辑链（大白话版）

生态网络不是"随便画几条漂亮的线"，它是一条严密的推理链，缺一环结果就不可信：

```
① 源地   哪些地方是"动物的家"？→ MSPA 找大块、连接好的核心生态斑块
              （不是所有林地都算：小块、边缘、被切断的都不行，阶段2细讲）
② 阻力面  从一个家走到另一个家有多难？→ 给每种土地/坡度/道路打"走路成本"
              （阻力值要有依据，阶段3细讲）
③ 廊道   最省力的路线是哪条？→ MCR 最小累积阻力路径
              （答案唯一、可复现，阶段4细讲）
④ 节点   路线上哪里最挤、哪里堵？→ 电路理论找夹点+障碍点
              （MCR 只给一条路，电路理论给"所有可能的路"，阶段5细讲）
⑤ 优先级  先修哪个节点？→ 节点 × 退化区 × 优先区 × 工程 条件叠加
              （连通性视角 ≠ 工程可行性，阶段6细讲局限）
```

**为什么不能跳步**：跳过②直接画线 = 凭感觉连线，无法解释"为什么连这而不连那"；
跳过①只留大斑块 = 源地太小没有代表性；没有④ = 只有"一条路"没有"堵点"，
修复建议就落不到具体的桥/涵洞/路口上。这就是"源地—阻力—廊道—节点"四件套
缺一不可的原因，也是答辩时最容易追问的地方。
