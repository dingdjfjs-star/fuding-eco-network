# 小白学习手册 —— 福鼎生态网络项目（MSPA+阻力面+MCR+电路理论）

> 写给凌晨睡醒的你。假设你只会一点 Python 和 GIS 软件，每句话都说人话。
> 配套：`docs/阶段0~阶段6_*.md`（逐阶段讲解）、`report/项目报告.md`（正式版）。

## 1. 这个项目整体逻辑链是什么（一段话版）

生态网络 = **给动物修"高速公路网"**。四步：

```
源地(家) → 阻力面(走哪条路费劲) → 廊道(最省力的路) → 节点(路上哪最堵/哪修了最值)
```

1. **源地**：用 MSPA 从土地覆盖里挑出"大块、内部完整"的生态斑块当动物的家（13 个）
2. **阻力面**：给每个 30m 像元打"步行难度分"——林地 1 分好走，县城 100 分走不了（5 因子 max 融合）
3. **廊道**：源地两两之间，用 MCR 算出累计成本最低的一条线（78 条）
4. **节点**：电路模拟找"所有电流挤在一起"的夹点；恢复实验找"修好后收益最大"的障碍点
5. **优先级**：节点 × 姊妹项目优先区 × 保护地 × 道路 × 村庄，排出先修谁、修什么

和姊妹项目的关系：姊妹项目回答**"面"**（哪里退化重→先修哪里），本项目回答**"线+点"**
（家和家之间怎么连、路上哪最堵）。两个项目用同一套数据底座，结果能互相叠加印证。

## 2. 四个核心概念分别在干什么（大白话）

### 2.1 MSPA（形态学空间格局分析）
只问一个问题："**这块林子的结构是什么角色？**"
- 把生态用地变成黑白二值图（白=林地/灌木/草地/湿地）
- 用数学形态学（腐蚀/膨胀）做"体检"：**核心区**=离边缘超过 1 像元的腹地（能养种群）；
  **边缘**=贴边一圈；**桥接**=连接两个核心的窄带；**孤岛**=没核心的小碎斑
- 为什么不能"林地=源地"？小块林地容易局部灭绝、边缘干扰大——只有**核心区**够格当源
- 我们为什么自己写而不是装 Guidos？Guidos 是 Windows GUI 工具，夜跑环境装不了/没法脚本化；
  Python 形态学能复现"核心区"这一最关键类的口径（差异逐条写在 stage2_mspa.json）

### 2.2 阻力面
回答"**动物走每一步有多难**"。像元的"步行成本"：
- 林地 1 分（随便走）→ 耕地 30 分（要绕/有干扰）→ 县城 100 分（走不了）
- 道路不是一条线而是"衰减场"：高速路面上 400 分，离开 300m 衰减到 1 分
  （公式 `res = 1 + (peak−1)·e^(−d/λ)`，指数衰减平滑又单调）
- 五因子（地类/坡度/道路/居民点/水系）各算一张，**取 max**（最差的一票否决，保守）
- 阻力值不是拍脑袋：有文献的标文献，没有的标"经验值"并在敏感性分析里量化影响

### 2.3 MCR（最小累积阻力）
回答"**从家 A 到家 B，最省力的路线是哪条**"。
- 就是"阻力地形"上的最短路：Dijkstra 算法在 560 万像元的图上找累计成本最小路径
- MCR 值 = 沿途所有步的成本累加（单位：阻力×米）；路径 = 廊道
- 特点：**只认一条路**——像导航软件"最快路线"，但动物不一定都走这一条

### 2.4 电路理论
回答"**如果所有可能的路都走，哪里最挤**"。
- 把景观想象成电阻网络：源地=电源/接地，像元间电导=1/阻力
- 注入电流后，电流会**自动分配到所有并联路径**（便宜的路径分到多、贵的分到少）
- 电流大的像元=夹点（生态流必经之地）；这就是它和 MCR 的本质区别：
  **MCR 给一条线，电路给一张"流量图"**
- 本项目的简化：电路跑在已提取的廊道网络上（不是全景观），因为全景观 560 万节点的
  线性方程组夜跑算不动；简化口径让夹点偏保守（写进报告局限）

## 3. 代码每一段在干什么（scripts/ 逐个说）

| 脚本 | 干什么 | 关键点 |
|---|---|---|
| s1_data_prep.py | 统一网格+矢量烧栅格 | **重投影坑**：GeoJSON 经纬度→UTM 必须先 pyproj 变换 |
| s2_mspa.py | MSPA 七分类+选源地 | 核心=3×3全前景腐蚀；源地=核心≥100ha 且 NDVI≥0.40 |
| s3_resistance.py | 五因子阻力面 | EDT=距离变换（算每个像元到最近道路的距离）；指数衰减 |
| s4_mcr.py | 78 对廊道 | 虚拟超级源法（多起点=给源加个 0 成本中转站）；回溯=沿 predecessor 指针倒走 |
| s4b_save_paths.py | 路径落盘 npz | 障碍点重算需要"哪条廊道经过哪个窗口" |
| s5_nodes.py | 夹点+障碍点 | 拉普拉斯矩阵+线性求解=spsolve；接地=把该行改成单位行 |
| s6_priority.py | 措施决策表 | 每个节点 300m 窗口查地类构成→查规则表给措施 |
| s7_report.py | 报告生成 | 从 JSON 取数拼报告——数字永不手抄，天然可溯源 |

**读代码的三个钥匙**（看不懂代码时先找这三个）：
1. `rasterio.open(...).read(1)` = 读一张 GeoTIFF 成 numpy 数组（行×列的网格数）
2. `np.where(mask)` = 所有满足条件的像元的（行,列）坐标——栅格分析的万金油
3. `scipy.sparse` 稀疏矩阵 = 只存"有边的位置"，560 万节点的图才能装进内存

## 4. 常见报错和排查顺序（今晚实测全遇到过）

| 报错/症状 | 人话翻译 | 排查顺序 |
|---|---|---|
| `UnicodeEncodeError: 'gbk' codec` | 控制台打不出 ²/⁰ 等字符 | 加 `sys.stdout.reconfigure(encoding="utf-8")`，与数据无关 |
| 矢量烧录全是 0 像元 | 几何在网格外=投影没变换 | 先查 CRS（GeoJSON 常是 4326），pyproj 重投影后再 rasterize |
| `AttributeError: 'tuple' object has no attribute 'c'` | 仿射变换传成了 6 元组 | `rasterio` 要 `Affine` 对象：`Affine(*t[:6])` |
| MCR 全部 inf / 路径 1 像元 | 起点没接进图，或 0 权边被削 | 探针打印 `d.min/isinf`；scipy CSR 加法削显式 0 → 用 ε=1e-3 |
| 形态学/逐斑块循环卡死 | 全图操作×几万次 | find_objects 拿包围盒，在小窗口里算 |
| 重采样后廊道"穿山过海" | 上采样/聚合引入假连通 | MSPA 用原生分辨率；mode 聚合会吞窄缝 |
| 两个栅格相减报 shape 不匹配 | 网格规格漂移 | 阶段1 的断言（CRS/尺寸/transform）别删 |
| `Mean of empty slice` | 对空数组求均值 | 上游全空→先查为什么全空（一般是掩膜/阈值错） |

**排查心法**：先查"输入对不对"（投影/网格/nodata），再查"中间量对不对"（探针打印
min/max/形状），最后才怀疑算法本身。今晚 8 个坑里 7 个是输入/口径问题，0 个是 Dijkstra 写错。

## 6. 老师可能追问的 5 个问题及回答

**Q1：你的源地为什么只有 13 个？阈值 100ha 怎么定的？**
答：MSPA 核心区≥100ha 起筛，是县级尺度研究的常用档位（50~100ha 区间），本项目取保守值；
再叠加 NDVI≥0.40 剔除退化斑。敏感性可以通过调阈值做（列为下一步），但源地数量对阈值
不敏感的部分（两大核心）是稳定的——核心结论不依赖阈值细节。

**Q2：阻力值是你拍的吧？凭什么林地=1、县城=100？**
答：锚点值（林地 1/建成区 100）是文献通用口径；中间档位是经验值，我在报告里逐条标了
"经验值"而不是装作有依据。更重要的是做了敏感性分析：道路/居民点阻力 ×0.5~×2，
廊道空间重合率（Jaccard）与长度变化量化了"拍脑袋"的影响范围——这是对参数不确定性的
正面回答，而不是回避。

**Q3：MCR 和电路理论你都用了吗？为什么？**
答：用了。MCR 给"最省力的一条路"（路径明确、可复现、工程上能落地）；电路理论给
"所有可能路径上的流量分布"（发现夹点）。MCR 的弱点是忽略备选路径——两条并行廊道
断一条还有一条，MCR 看不出来，电路理论看得出来。两者互补：廊道用 MCR 提取，
节点用电路找夹点+恢复实验找障碍点。

**Q4：你的电路理论是真的 Circuitscape 吗？**
答：不是，是简化口径——电路跑在已提取的 MCR 廊道网络上（数万节点），不是全景观
（560 万节点跑不动）。差异是：全景观版能发现"廊道外"的绕行路径，我的夹点因此偏保守
（保守方向对修复决策是安全的：漏报的夹点比虚报的危险小）。这是算力与口径的权衡，
报告里如实写了。

**Q5：你这个结果敢直接给政府用吗？**
答：不敢，也不该。三个前提：①阻力值多为经验值档位，绝对量级未实测；②保护地是 OSM
弱参考，生态红线未取得；③连通性视角≠工程可行性（权属/资金/地形都没考虑）。它的
正确用法是**筛选工具**——把"最该去看现场的 15 个点位"从全县范围里筛出来，配合
踏勘和部门协同再做工程决策。这也是我在报告"局限"一节写明的。
