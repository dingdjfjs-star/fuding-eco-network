# 阶段2 MSPA 源地 / 阶段3 阻力面（完整讲解版）

> 2026-11-06 凌晨 · 无人值守夜跑

## 2.1 MSPA 七类的大白话 + 为什么不能"林地=源地"

| 类 | 大白话 | 生态含义 |
|---|---|---|
| 核心区 Core | 离边缘>1像元的腹地 | 内部干扰小，能养种群 → **源地候选** |
| 边缘 Edge | 贴着外部的一圈 | 光照/风/人为干扰大，边缘物种才喜欢 |
| 孔隙 Perforation | 被林地包住的小空地 | 林中农田/裸地，内部扰动源 |
| 桥接区 Bridge | 连接两个核心的窄带 | 潜在廊道，断了两个核心就断联 |
| 环道 Loop | 连接同一核心两端的带 | 备用路线，被切断仍有回路 |
| 支线 Branch | 死胡同 | 临时觅食地，通达性差 |
| 孤岛 Islet | 没有核心的小斑块 | 容易局部灭绝，不宜当源地 |

本项目实测（10m 原生分辨率）：核心 2612.8 km²（占前景94.5%）、边缘 25.0、孔隙 104.2、
**桥接 0、环道 0**、支线 23.3、孤岛 4.5 km²；源地 13 个（2 巨型 + 11 卫星）。

## 2.2 桥接=0 的方法学解释（重要，答辩会问）

WorldCover 把茶园/园地归入"树冠覆盖(10)"，加上山地县森林天然连片，
10m 口径下前景 91% 连通——**破碎化体现在阻力面（道路/居民点/耕地谷地）而非二元前景**。
若有三调/国土变更调查（园地单列），桥接/环道类会显著增多。
MSPA 结论仍然可用：核心区筛源地；廊道载体是阻力面（阶段3-4）。

## 2.3 简化 MSPA vs Guidos Toolbox（逐条差异）

1. 结构元固定 3×3/8邻接，边缘宽 1 像元（10m），无第三维与自定义宽度
2. bridge/loop/branch 用"连通函数"近似（接触核心数+接触点聚类）替代形态学收窄精确口径
3. 与核心直接相接的 1 像元过渡带计入边缘
4. 源地只用核心区类——该类口径保守、与 Guidos 一致性最高，对后续廊道无系统性偏差

## 2.4 30m-mode vs 10m 原生分辨率（v1/v2 对比实验，写进报告）

v1 用 30m mode 重采样前景：核心占前景 88%、桥接=0——mode 聚合把 30~100m 窄谷
"投票吞掉"，假连通。结论：**MSPA 必须用原生分辨率跑**；30m 网格留给 MCR
（效率），源地是面状对象，众数重采样不丢拓扑。

## 3.1 阻力面：五因子与赋值依据

| 因子 | 赋值 | 依据 |
|---|---|---|
| 林地 10 | 1 | 文献通用锚点（最低阻力） |
| 灌木 20 | 3 | 经验值（次生植被） |
| 草地 30 | 10 | 经验值（含园地草被混分） |
| 耕地 40（含茶园） | 30 | 文献区间 20~100 取中低档：条垦常绿茶园通行阻力低于裸田【需我确认】 |
| 建成区 50 | 100 | 文献通用锚点（硬质化） |
| 裸地 60 | 80 | 经验值（采石/裸土） |
| 水体 80 | 100 | 经验值（陆生动物视角；海域在缓冲区） |
| 湿地 90 | 20 | 经验值（本身是栖息地） |
| 坡度 | 1/2/4/8/16/32（<2/2-5/5-8/8-15/15-25/>25°） | 经验值等比翻倍；与2点项目"53.2%坡度>15°"呼应 |
| 道路 | 3级峰值400 λ300m；2级200 λ200m；1级100 λ100m | 文献区间+经验值；指数衰减 res=1+(peak−1)·exp(−d/λ) |
| 居民点 | 峰值300 λ250m | 经验值（村庄/家犬/采集干扰半径） |
| 水系 | 溪流像元60 | 经验值（跨溪有成本非阻断；大河由水体100兜底） |
| 融合 | **max**（最强障碍主导） | 保守口径；加权求和/乘积为备选【需我确认】 |

## 3.2 敏感性分析设计

扰动对象：道路+居民点阻力 ×0.5（low）/ ×2.0（high）——线性基础设施是修复工程
最常干预的对象，也是阻力面里最"人为"的部分。指标：同对廊道 90m 缓冲 Jaccard
重合率 + 廊道长度变化率（阶段4 输出）。
