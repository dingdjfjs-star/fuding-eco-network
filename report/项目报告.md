## 4 方法（技术路线）

```
①MSPA源地  ②阻力面  ③MCR廊道  ④电路理论节点  ⑤修复优先级
前景(林/灌/草/湿地)  5因子max融合  8邻接Dijkstra  廊道网络电路模拟  节点×优先区×工程
 → 13源地          → base/low/high → 78对路径     夹点+障碍点      措施决策表
```

- **MSPA**（简化口径，差异见 stage2_mspa.json）：核心区=源地候选，≥100ha 且 NDVI≥0.40
- **阻力面**：土地利用+坡度+道路+居民点+水系，max 融合，敏感性=道路/居民点×0.5/×2
- **MCR**：逐源虚拟超级源+Dijkstra，predecessor 回溯 78 对走廊
- **电路理论（简化）**：在 MCR 廊道网络上逐源注入 1A、其余源地接地，电流=生态流强度；
  夹点=电流 P95 聚类；障碍点=耕地/建成区/裸地窗口恢复增量重算 MCR

## 6 结论

1. 福鼎生态源地为"两大核心+11 卫星"格局，网络骨架是双核互联+卫星挂接
2. 廊道穿越的阻力热点集中在**道路线位与县城周边**（敏感性分析确认道路/居民点参数对廊道位置影响显著）
3. 修复应优先投在**一级夹点+一级障碍点**：夹点保通（避免进一步切割），障碍点增益最大（恢复后 MCR 降幅最高）
4. 与姊妹项目一级优先区空间命中 5/31 个节点——两个项目结论互相印证、可互相引用

## 7 讨论（局限，如实写）

1. **WorldCover 园地口径**：茶园归树冠覆盖 → MSPA 前景过连（桥接=0）、滩涂归水体 → 源地缺滩涂。
   有三调/国土变更调查数据应重跑 MSPA；滩涂源地建议用专题湿地数据补
2. **电路为廊道网络简化口径**：全景观 Circuitscape 能发现"廊道外"的备选路径，本方案只能在已提取的
   廊道网络内分配电流——夹点位置偏保守
3. **障碍点非全网格扫描**：top15 窗口增量重算，候选来自廊道沿线耕地/建成区/裸地
4. **阻力赋值多为经验值**：敏感性分析已量化其影响（§5.3），但绝对量级未经实测验证
5. **连通性视角≠工程可行性**：未考虑用地权属、资金、地形可达性、施工窗口；措施为方向性建议
6. 无野外验证：廊道/节点位置未做实地核查（下一步第一项）
